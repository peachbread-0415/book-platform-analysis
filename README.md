# 과거 성과 기반 플랫폼 투자 효율성 분석

교보문고·알라딘·예스24·영풍문고 4대 도서 플랫폼의 리뷰·평점·베스트셀러 데이터를 통합 분석하여  
플랫폼별 도서 성과 구조와 평가 요인을 정량적으로 비교한 프로젝트입니다.  
이를 통해 마케팅 투자 우선순위 및 플랫폼별 차별화 전략을 수립하기 위한 근거를 도출하였습니다.

---

## 1. 프로젝트 개요

### 프로젝트 배경
- 도서 플랫폼별 리뷰·평점·베스트셀러 선정 기준이 상이함  
- 동일 도서라도 플랫폼에 따라 평가나 감성의 차이가 존재할 가능성 검증  
- 각 플랫폼의 ‘성과 효율성’을 정량화하여 투자/마케팅 전략 근거 확보 목적

### 프로젝트 목적
- 도서 평가 점수와 베스트셀러 여부의 관계 분석  
- 감성 분석 기반 도서 성과 요인 식별  
- 장르·출간시기·저자 등 세부 속성이 성과에 미치는 영향 파악  
- 플랫폼 간 교차등재율을 통해 파급력 및 영향 구조 분석

## 4. 분석 설계

### 분석 지표 정의

| 지표 | 설명 |
|:--|:--|
| 리뷰 수 | 플랫폼별 리뷰 개수 |
| 감성 점수 | 긍정·부정 비율 기반, 부정 비율이 높을 경우 0 처리 |
| 별점 평균 | ISBN별 평균 평점 |
| 베스트셀러 여부 | 0: 비등재 / 1: 등재 (kyobo_best, aladin_best, yes24_best, yp_best) |

**도서평가점수 산식**
<br>
도서평가점수 = 0.05 × 리뷰수 + 0.5 × 감성점수 + 0.45 × 별점


1점당 효과  
감성점수 1.4%p, 리뷰수 20개, 별점 0.06점 차이

## 6. 주요 EDA 결과

### ① 장르별 도서평가점수
- 문학·자기계발·역사 장르가 상위권  
- IT·예술·과학은 리뷰수 적지만 감성점수 높음 → 충성 독자 중심  
- 장르별 점수와 베스트셀러 등재율 간 상관 r=0.42

### ② 출판시기별 트렌드
- 2019~2020년: 코로나 영향으로 점수 급상승  
- 2021~2023년: 스테디셀러 중심으로 안정화  
- 2024~2025년: 신간 긍정 반응 증가 → 마케팅 효과 반영 추정

### ③ 저자별 성과
- 설민석·히가시노 게이고·김난도 등 베스트셀러 저자 다수  
- 저자–베스트셀러 간 관계 유의(p<0.05)  
  → 유명 저자는 베스트 형성의 강력 변수, 비베스트 영역은 주제·장르 영향 우세

### ④ 도서평가점수 민감도
- 리뷰수가 점수 상승에 가장 큰 기여도(+1.012)  
- 감성점수·별점은 보조 효과  
  → 리뷰 유도 전략이 플랫폼 성과의 핵심 변수

### ⑤ 플랫폼별 감성/별점 구조
- 긍정 리뷰 비율: 80~92%, 5점 쏠림 현상 뚜렷  
- 교보·영풍: 긍정 편향형 (신뢰·충성 중심)  
- 알라딘: 부정·1점 비중↑ (비판적·커뮤니티형)  
- 예스24: 3점 비중↑ (중립·균형형)

## 7. 가설 검정 결과 요약

| 가설 | 결과 | 해석 |
|:--|:--|:--|
| H1. 도서평가점수와 베스트셀러 여부는 관계가 없다 | 기각 (p<0.05) | 베스트셀러가 비베스트셀러보다 점수 유의하게 높음 |
| H2. 저자와 베스트셀러 여부는 독립이다 | 기각 (p<0.05) | 유명 저자일수록 베스트셀러 가능성↑ |
| H3. 단일 플랫폼 베스트셀러는 비베스트셀러보다 점수가 높다 | 채택 (p<0.05) | 단독 베스트도 상향효과 존재 |

## 9. 전략적 시사점

### 투자 우선순위
- 교보 중심 집중, 예스24 보완 투자  
- 알라딘은 취향 기반 세분 타깃용, 영풍은 장기 브랜딩 채널로 활용

### 리뷰 활성화 전략
- 리뷰 1개 = 점수 +1 수준 효과  
  → 후기 인센티브·리뷰어 등급제·추천 리워드 도입

### 저자별 캠페인 분리
- 유명 저자 → 교보 집중 프로모션  
- 신예·매니아 저자 → 알라딘·예스24 중심 콘텐츠 확산

### 교차등재 관리
- 베스트 간 중복(교보–예스24 r=0.78) → 공동 프로모션 효율 높음  
- 교보↔알라딘 음의 상관(-0.25) → 상반 타깃 공략 가능
